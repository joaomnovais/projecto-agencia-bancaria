# Projecto Agência Bancária

### Visa desenvolver e gerenciar um banco de dados para um banco comercial  que possui várias agências espalhadas pelo __*País.*__  

O banco precisa armazenar informações sobre:
1. Agências
2. Clientes
3. Contas 
4. Transações
   
Cada cliente pode ter uma ou mais contas, e cada conta pertence a uma agência específica.  As transações (depósitos, saques, transferências) são registradas para cada conta,  e o saldo da conta deve ser atualizado conforme as transações são realizadas.

Lista de Tarefas:
- [ ] Criar o Front-End
- [ ] Finalizar a reunião com o cliente
